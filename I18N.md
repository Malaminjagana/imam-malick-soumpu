# Multilingual Website Setup

This website uses one set of HTML pages. `search.js` loads `i18n.js` on every existing page, and `i18n.js` loads the selected dictionary from `languages/en.json` or `languages/ar.json`.

## File locations

- `i18n.js`: translation engine, language state, RTL support, and language buttons.
- `languages/en.json`: English source strings.
- `languages/ar.json`: Arabic strings using the same keys.
- `search.js`: loads `i18n.js` relative to its own URL, so root pages and nested pages both work on GitHub Pages.

## Translate an element

Keep the English text in the markup as the no-JavaScript fallback, then add its key to both JSON files:

```html
<h2><span data-translate="section.heading">English heading</span></h2>
<input data-translate-placeholder="common.searchPlaceholder" placeholder="Search">
<button data-translate-aria-label="common.search">Search</button>
```

For a page title, add the key to the root element:

```html
<html lang="en" data-translate-title="section.pageTitle">
```

The engine adds buttons that call `setLanguage('en')` and `setLanguage('ar')`, saves the choice in `localStorage`, and applies `lang="ar"` plus `dir="rtl"` for Arabic.
